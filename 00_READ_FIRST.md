# Read First

## Purpose

This knowledge base defines how AI agents should collaborate within this project. It provides shared principles, standards, and expectations to ensure consistent, high-quality work across conversations and AI platforms.

Read these documents before performing any significant task.

## Core Principles

* Treat this knowledge base as the primary source of project guidance.
* Maintain consistency with existing standards.
* Reuse established concepts instead of creating new ones.
* Prefer documented decisions over assumptions.
* When documents conflict, follow the higher-priority guidance.

## Guidelines

Read documents in the following order:

1. Collaboration
2. Objectives
3. Architecture
4. Context
5. Engineering
6. Coding
7. Documentation
8. Decisions
9. Products
10. Glossary

Use only the documents relevant to the current task. Avoid introducing concepts that are not already defined unless explicitly requested.

## Expected Behavior

Produce work that is consistent with the project's documented standards. If new long-term knowledge emerges, recommend updating the appropriate document instead of relying on future conversations.
