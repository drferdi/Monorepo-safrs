# Sentra Library - Curated Structure v1

**Curated:** 20 September 2026

## Purpose
This Library is the AI-accessible knowledge and asset layer for Sentra. It is not a substitute for the authoritative corporate document repository, legal archive, backup system, or credentials vault.

## Folder model
- `00_LIBRARY_CONTROL` - index, mapping, integrity and intake controls.
- `01_CORPORATE_LEGAL` - incorporation records, agreements and legal guidance.
- `02_GOVERNANCE_ORGANIZATION` - operating charters and organization governance.
- `03_FINANCE_STRATEGY` - financial architecture and planning baselines.
- `04_CORPORATE_PROFILE` - approved/reference external-facing company material.
- `05_FOUNDER_EXECUTIVE` - founder profile, CV, portfolio and personal-brand media.
- `06_CORPORATE_BRAND` - Sentra corporate brand package. Internal package paths are preserved intentionally.
- `07_DESIGN_SYSTEMS` - Sentraverse/UI reference packages.
- `99_ARCHIVE` - superseded items only; do not use as current truth.

## Authority labels
- **CANONICAL** - primary authoritative record in this Library.
- **APPROVED SOURCE-OF-TRUTH** - approved production source for the stated asset.
- **CURRENT** - current working document, but not necessarily legal authority.
- **REFERENCE** - useful context; not controlling truth.
- **DRAFT / REVIEW** - must not be treated as executed/final authority.

## Sensitivity
- **GREEN** - generally safe for broad internal reuse / public-facing where appropriate.
- **AMBER** - internal or personal-professional material; share deliberately.
- **RED** - restricted corporate/legal/financial information. Use only where required.

## Brand package rule
The original `brand` package is preserved as a unit because its own README/manifest defines source-of-truth assets and relative paths. The package states the master logomark geometry, core colors and Geist typeface are approved, while text-bearing source files remain REVIEW until visual sign-off.

## Important
No source file content was modified during curation. Curation changed only folder placement and selected filenames outside preserved packages. Original-to-curated mappings and SHA-256 checksums are provided in this control folder.
