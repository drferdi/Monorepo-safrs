# Sentra Typography Guide v1.0

- **Primary:** Geist Sans (Vercel)
- **Technical/data/code:** Geist Mono
- Suggested weights: body 400; UI 500; heading 500-600; wordmark 600.
- Keep tracking neutral for body text. Tighten large headings carefully; do not over-track the primary wordmark.
- Font binaries are not bundled. Install from the official Geist release or via `npm i geist`.
