# Logo variations

Primary corporate lockup: **Sentra Artificial Intelligence**.
Secondary compact lockup: **Sentra AI**.

All SVG lockups use live `Archivo` text so the approved typeface remains editable and exact when Archivo is installed or loaded by the product. The font binary is intentionally not bundled here (see `packages/token/assets/fonts/archivo/`). For production print artwork, install Archivo and convert the text to outlines in the design tool before final export.
