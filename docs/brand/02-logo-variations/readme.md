# Logo variations

Primary corporate lockup: **Sentra Artificial Intelligence**.
Secondary compact lockup: **Sentra AI**.

All SVG lockups use live `Geist` text so the approved Vercel typeface remains editable and exact when Geist is installed or loaded by the product. The font binary is intentionally not bundled. For production print artwork, install the official Geist release and convert the text to outlines in the design tool before final export.
