## How to read the status columns

| Column | Values |
| --- | --- |
| **Implementation** | `Shipped` · `Shipped (branch only)` · `Partial` · `Designed` · `Absent` |
| **Tests** | `Covered` · `Partial` · `None` |
| **Docs** | `Canonical` · `Wiki` · `Partial` · `None` |
| **Dashboard** | `Connected` · `Partially Connected` · `Not Yet Connected` · `Requires Configuration` · `Requires Human Action` · `Error` |
| **Risk** | SAFRS tier `R0`–`R3` for changing the feature |

`Shipped (branch only)` means the code exists and is tested, but is not on `main`. The dashboard
must show these — hiding them would misrepresent what the repository can do.

### Corpus Engine detail

The largest capability in the repository and the one most at risk of being invisible.

- **Purpose:** turn a curated medical PDF corpus into an agent-queryable knowledge base with citations.
- **Pipeline:** PDF → Docling parse → canonical DoclingDocument JSON (source of truth on disk) →
  quality gate → block extraction → chunking → BGE-M3 embeddings → PostgreSQL/pgvector.
- **Modules:** `parse`, `canonical`, `blocks`, `quality`, `chunker`, `flow`, `query`, `repair`,
  `prewarm`, `calibrate`, `logic_version`, `config`.
- **Real data** (gitignored `database/`, not in git — back it up separately):
  93 canonical JSON documents + `manifest.jsonl`, ~90 curated source PDFs across 33 medical
  specialties, CocoIndex LMDB state, a dated `corpus_local.dump`, pipeline and prewarm logs.
- **Runtime requirements:** Python 3 + `uv`, local GPU for embeddings, PostgreSQL with pgvector on
  port `54329`.
- **Concurrency rule:** single writer, enforced by `database/corpus.lock`. Two pipeline sessions
  raced on 2026-08-12 and corrupted `manifest.jsonl`.
- **Danger:** `git clean -xdf` at the repository root deletes the entire corpus. Git does not
  protect it.
- **Dashboard obligation:** show it as implemented-on-a-branch, expose corpus statistics read from
  `manifest.jsonl` (safe, read-only), and offer merge-to-`main` as a **Requires Human Action** step
  rather than a button.
