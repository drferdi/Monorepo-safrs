SENTRA / DESIGN-SYSTEM Exception request

EXC-01 Against prohibition · neumorphism

Button treatments

Five ways to make a button feel pressable. Press each one — the difference is in the moment of contact, not in the still image. Each is measured against WCAG 2.2 criterion 1.4.11, which requires a control's boundary to reach 3:1 against what sits next to it.

Recommendation

C · Hard ledge

Physical, distinctive, and the boundary stays at 18.68:1. It reads as letterpress rather than as soft plastic — closer to where the rest of this system already lives.

01

Treatments

Press to compare
AFlat — current Pass

boundary 18.68:1

What we ship today. Nothing moves on press. Honest and calm, but the button gives no physical answer when it is clicked.

BPress motion only Pass

boundary 18.68:1

Identical at rest; drops 1px while held. The tactility costs nothing because it exists only during the press. Cheapest option, and it survives reduced-motion by simply not moving.

CHard ledge Pass

boundary 18.68:1 · ledge 3.21:1

A solid 3px offset slab, no blur. On press the button travels onto its own shadow and the slab disappears. This is print register, not soft plastic — it belongs to the same tradition as the rest of the system.

DInner bevel Pass

boundary 18.68:1

A 1px light line inside the top edge and a darker one at the bottom. The dimension is contained entirely within the button, so nothing bleeds onto the canvas. Subtle — arguably too subtle to notice.

ESoft neumorphism — border kept Pass

boundary 18.68:1 · carried by the border, not the shadow

Your request, made safe. Soft dual shadows for the extruded feel, but the 1px border stays so the boundary still measures. Press inverts the shadow inward. This is the closest legitimate reading of "minimal neumorphism".

F was evaluated and rejected. Its boundary measured 1.09:1 against a required 3:1, and its disabled and pressed states were visually identical. The row is kept struck rather than deleted so the option is not proposed again without new evidence.

The current shadow rule reads: shadow is reserved for temporary overlays only. C, D and E all need that sentence amended to allow shadow on controls. That is a one-line change and an honest one — but it must be written into the system, not left as an undocumented habit.
