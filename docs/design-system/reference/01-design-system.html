01

Doctrine

Six rules that settle most arguments
R1

Structure before style

Grid, hierarchy and content order are decided before any colour or type choice. A layout that only works once it is styled is not resolved.

R2

Every element earns its place

An element must orient, inform, group, act, or give feedback. If it does none of these, it is removed — not made subtler.

R3

Type does the structural work

Hierarchy comes from size, weight, position and space. Not from boxes, fills or shadows. Containers are the last resort, never the first.

R4

Colour is meaning, never filling

Brand colour marks identity and state. Status colour reports condition. Neither is ever used because a region looked empty.

R5

Never colour alone

Every status carries a distinct glyph and a word. The interface stays fully readable in greyscale and to a colour-blind operator.

R6

Say the true thing

The interface reports what happened, not what is comfortable. A run that produced unusable output says so, even when every process step succeeded.

Why one family

Archivo carries a width axis. The display voice comes from widening to 112, not from adding a second typeface. One family, two voices, one font payload.

Rules

  • Left aligned. Centred type only inside a modal title.
  • Three weights only: 400, 500, 600.
  • All numeric columns use tabular figures.
  • Uppercase is reserved for labels under four words.
  • Mono means machine-produced: IDs, paths, measurements, raw capture.
04

Colour

Contrast measured against white

The zone rule. Vermilion and crimson are close in hue — 1.91:1 apart. They are kept apart by location, not by hue. Vermilion lives only in chrome: wordmark, sequence numbers, active navigation, panel corners. Crimson lives only in content: verdicts, failed gates, defect marks. The two never appear in the same block. A screen that breaks this rule is a defect, not a variation.

The four-series ceiling

The ramp steps in lightness, not only in hue, so the series stay separable in greyscale, in print, and to a colour-blind operator. Adjacent steps are at least 1.6:1 apart.

A fifth hue cannot be added without colliding with a status colour or with vermilion. Beyond four series, label the marks directly instead. Every bar above carries its own name and value — no legend to cross-reference.

State tints

Tint only the worst state. Failing rows are tinted; warnings are not. If every condition gets a wash, the page is evenly coloured and nothing is urgent. The tint is a second signal behind the glyph and the word — never the first, and never the only one.

05

Line vocabulary

Four devices · each has a job

Corner marks

Four 10px brackets imply a container without drawing one. This replaces the card. Use only for a genuinely bounded object. Brackets turn vermilion when the object is the current focus.

SENTRA / MODULE-NAME

App chrome

Identity and module path, mono, wide tracking. Appears exactly once per screen, at the top. Repeating it on panels turns a signature into decoration.

Browser extension

Dash-rule label

A 28px hairline leading into a right-aligned meta label. Carries type, count or scope — never an action.

03

Sequence marker

Vermilion, mono, tabular. Used only where order is real information: pipeline stages, ordered checklists, navigation. Never applied to an unordered set to make it look systematic.

Shape

Structure is square. Radius 0 on tables, dividers, panels and surfaces. Radius 2px applies only to controls — buttons, inputs, selects. The curve means one thing: this can be touched.

Line

1px subtle for separation inside a group. 1px strong under a section title. 2px strong to close a page header. 2px status to open a verdict. Shadow is reserved for temporary overlays and for control affordance — never for stable content. Buttons carry a 3px solid ledge, no blur, which disappears as the control travels on press. Amended by EXC-01.

08

Prohibitions

Needs a written exception
  • Glassmorphism and background blur
  • Neumorphism and inset lighting EXC-01: hard ledge on controls only
  • Gradients as surface treatment
  • Glow, halo and ambient shadow
  • Radius above 2px on any element
  • A card around every section
  • Centred layout as the page default
  • Colour as the only carrier of status
  • Grey text below 4.5:1 for body copy
  • Icon-only actions without an accessible name
  • Decorative 3D or AI-themed imagery
  • Bento grids without an ordering logic
  • Vermilion inside the content zone
  • Crimson inside the chrome zone
  • Motion longer than 200ms
  • Numbering an unordered set
