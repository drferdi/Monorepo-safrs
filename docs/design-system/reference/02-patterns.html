01

Icons

20px canvas · 1.5 stroke · butt cap · miter join

The spec governs, not the library. Most icon sets ship with rounded caps and joins. In a system built on hairlines and square corners, a rounded terminal reads as a foreign object. Any library may be adopted — Lucide, Phosphor, or a drawn set — provided its stroke-linecap is set to butt and stroke-linejoin to miter. The icons below are drawn to that spec.

16 · inline
20 · default
24 · empty state

When an icon is allowed

  • With a label, always. An icon reinforces a word; it does not replace one.
  • Alone, only when repeated. Close, more, and dismiss may stand alone because they recur everywhere and the shape is learned. Everything else keeps its text.
  • Never alone for a destructive action. Delete, revoke and block always carry a word.
  • Every icon-only control needs an accessible name via aria-label, and the SVG itself is aria-hidden.
  • No icon carries status alone. Status is glyph plus word, as set in the foundations.
02

States

Empty · loading · error

Empty is three different states, not one. Treating them alike is the most common failure in this category: a filtered list that says "Create your first run" is telling the operator something false.

EMPTY · A

No runs yet

A run pairs a source with an extractor and produces a dataset shard. Start by adding the source you want to crawl.

EMPTY · B

No runs match these filters

412 runs exist. None of them are both failed and from this week.

EMPTY · C

Review queue is clear

All 27 flagged runs have been resolved. New ones will appear here as gates fail.

A explains what the thing is and offers the one action that creates it. B names the number that exists so the operator knows the data is not lost, and offers the way back. C is a report, not an invitation — it deliberately has no button.

LOADING · A

Skeleton — layout known

Used when the shape of the result is already known — tables, lists, detail panels. The skeleton mirrors the real layout so nothing jumps when data lands. A live region announces Loading runs to screen readers; the bars themselves are hidden from them.

LOADING · B

Progress — duration known

Extracting records 38%

412 of 1,084 · started 11:09:42

Used only when real progress can be measured. A bar that moves on a timer rather than on work completed is a lie, and operators learn to distrust it. When progress cannot be measured, use the skeleton instead — never a spinning full-page overlay.

ERROR

Three scopes

Crawl log could not be loaded

The run itself is unaffected and its gate results are shown above. The log service returned 503 at 11:12:04.

Section scope. One region failed; the rest of the page still works. Say what is unaffected — that sentence prevents an unnecessary escalation.

Showing cached results from 10:47

Live gate evaluation is unavailable. Figures may be up to 25 minutes old.

Degraded, not failed. The page works but the data is stale. This is the state most systems skip, and the one that causes the worst decisions when it is skipped.

Never write "Something went wrong." Every error states what failed, what still works, when it happened, and the one action available. If none of the four is known, that is a logging defect, not a copy problem.

03

Forms

Validate on blur · re-validate on change

Live — leave the field empty and tab out

Gate profile

Anatomy

PartRule
LabelAlways visible. Placeholder is never a substitute — it disappears exactly when it is needed.
RequirementMarked with the word, not an asterisk. Both Required and Optional are shown when a form mixes them.
HelpBelow the control, before the error. Explains the consequence, not the format.
ErrorBelow the control, in the error colour, with the alert glyph. Names the fix, not the violation.
Invalid controlaria-invalid, 2px border and a tint — three signals, so colour is never alone.

Validation timing. Never on keystroke for a first attempt — it scolds the operator mid-word. Validate when the field is left. Once a field has errored, re-validate on every change so the error clears the moment it is fixed. On submit, validate everything and move focus to the first invalid field.

04

Overlays

One at a time · Esc always closes

Live — open, tab around, press Esc

Focus is the whole contract. On open, focus moves into the overlay. Tab cycles inside it and cannot escape. Esc closes. On close, focus returns to the exact control that opened it — so a keyboard operator never loses their place. An overlay that skips the return step strands them at the top of the page.

Modals are for decisions that must be made now, and for destructive confirmation. Drawers are for secondary work that runs alongside the page — filters, details, history. Toasts report what already happened. A toast never carries the only copy of important information, and a failure toast never auto-dismisses.

A modal never opens another modal. If a decision needs a second decision, the flow is wrong and belongs on a page. The scrim is ink 44% — dark enough to suppress the page behind, light enough that context is not lost.
