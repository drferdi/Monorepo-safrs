# SAFRS Tool and Network Inventory

The authoritative machine-readable inventory is `.safrs/tool-inventory.json`.

Tool availability does not grant permission. An agent may use only operations allowed by the intersection of its identity, role, task scope, environment, repository policy, and risk tier.

Inventory entries record owner, purpose, allowed operations, data scope, authentication, network endpoints, provenance, and review status. New networked tools, endpoints, or authentication methods require an R2 governance change and designated review. Production credentials remain forbidden for coding agents.
