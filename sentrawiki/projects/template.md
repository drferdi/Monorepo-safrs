# Capsule template

**Path:** `projects/_template/`
**Contract:** `project.contract.json` id `template/project` — placeholders only.

Start new capsules from this tree and from `docs/governance/SAFRS_PROJECT_CAPSULES.md`. Replace every `REPLACE_*` field before activation. Do not copy `projects/internal/golden-path`.

Scaffolding CLI: `pnpm project:new` (`tools/project-wizard`).
