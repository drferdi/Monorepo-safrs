# Project Capsules

Each active product, service, or bounded system lives in `projects/<domain>/<capsule>/` and follows `docs/governance/SAFRS_PROJECT_CAPSULES.md`. Domains group capsules that share a compliance and data-handling context; a domain folder carries only `AGENTS.md` and `README.md`.

Copy `projects/_template/` to create a capsule, replace all placeholders, register its sensitive paths, and run the repository verification suite. The template is governance scaffolding, not a product implementation.
