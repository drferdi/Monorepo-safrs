# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

In short: be respectful, give and accept constructive feedback, and put patient safety and
privacy first. Harassment, discrimination and the sharing of anyone's private or clinical
information are not acceptable.

Report unacceptable behaviour privately to the project owner through
https://ferdiiskandar.com. Reports are handled confidentially.
