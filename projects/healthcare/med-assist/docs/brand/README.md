# Asisten Medis — Monochrome Brand Asset Kit

Brand: **Asisten Medis**
Product: **Chrome Browser Extension / Clinical Decision Support System (CDSS)**
Style: **Monochrome**

## Folder guide

- `01_MASTER` — master stacked logo, icon/mark, wordmark, horizontal lockups.
- `02_WEBSITE` — header logos, website banners, Open Graph images.
- `03_FAVICON` — favicon PNG sizes, multi-size `.ico`, Apple touch, Android/PWA and maskable icons.
- `04_CHROME_EXTENSION` — extension icons for Manifest V3 and toolbar/action usage.
- `05_CHROME_WEB_STORE` — Chrome Web Store icon and promotional banner sizes.
- `06_SOCIAL_BANNERS` — square profile and generic light/dark banners.
- `07_IMPLEMENTATION` — ready-to-copy HTML favicon and Chrome manifest icon snippets.
- `08_PREVIEW` — contact sheet showing the main deliverables.

## Recommended usage

- Light background: use `*-black-*`.
- Dark background: use `*-white-*`.
- Browser extension icon: use `04_CHROME_EXTENSION/icon128.png` as the master store/extension icon and map the smaller supplied sizes in `manifest.json`.
- Website header: use `02_WEBSITE/logo-header-black-800x200.png` or the white variant.
- Favicon: use `03_FAVICON/favicon.ico` plus the PNG/Apple/PWA assets.
- Social sharing: use `02_WEBSITE/og-image-light-1200x630.png`.

## Notes

The package preserves the approved monochrome visual direction: rounded clinical-intelligence form, stethoscope, medical cross, and `Asisten Medis / CDSS` identity.
