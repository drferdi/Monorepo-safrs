# Sentra Artificial Intelligence Brand Kit v1.0

This package contains ready-to-use Sentra Artificial Intelligence assets for website, app interface, favicon, Open Graph preview, and social media usage.

## Recommended primary usage
- Primary logo: `01_logo/png/sentra_artificial_intelligence_logo_horizontal_white_transparent.png`
- Primary background: pure black `#000000`
- Avatar/favicon/app icon: `01_logo/png/sentra_artificial_intelligence_logomark_white_transparent.png`
- Website preview image: `02_website/og_image_1200x630.png`

## Folder map
- `01_logo/` - horizontal logo, logomark, wordmark, PNG and SVG-wrapped variants.
- `02_website/` - favicon, app icons, navbar logos, Open Graph image.
- `03_social/` - profile avatar, X header, LinkedIn covers, YouTube channel art, Instagram templates.
- `04_brand_guide/` - concise brand guideline in PDF and Markdown.
- `05_tokens/` - CSS variables, Tailwind token JSON, brand config.
- `06_preview/` - one-page contact sheet preview.

## Important production note
The SVG files are raster-wrapped exports generated from the approved image. For final trademark-grade production, create a hand-tuned vector master in Figma/Illustrator and replace these SVG files.
