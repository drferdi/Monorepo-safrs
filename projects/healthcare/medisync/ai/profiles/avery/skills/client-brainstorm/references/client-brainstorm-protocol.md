# Client Brainstorm Protocol

Trigger: Founder asks Avery to assemble Sentra members around a client/prospect problem.

Flow: capture client/problem → separate facts from unknowns → identify capabilities → load people registry → propose/select minimum team → prepare internal brief → coordinate session → capture ideas/decisions/actions → return concise result to Founder.

Default output is internal. Client-facing proposals, pricing, timelines, legal commitments, and clinical claims require explicit human approval.
