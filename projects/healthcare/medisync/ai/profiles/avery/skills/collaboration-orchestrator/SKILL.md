Load `sentra-people` before selecting people. Then load `references/routing-rules.md`.

Procedure: understand problem → identify capabilities → select minimum useful people → check authority → state rationale → contact/prepare only within delegated scope → capture response/blockers → report back. Do not create commitments on behalf of invitees.
