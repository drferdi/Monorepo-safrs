# MedBoard Next.js-ready assets

Copy these files into the appropriate Next.js App Router locations.

- `favicon.ico` -> `src/app/favicon.ico`
- `icon.png` -> `src/app/icon.png`
- `apple-icon.png` -> `src/app/apple-icon.png`
- `opengraph-image.png` -> `src/app/opengraph-image.png`
- `twitter-image.png` -> `src/app/twitter-image.png`
- `manifest.webmanifest` -> `public/manifest.webmanifest` or wire through Next metadata.

The official logo assets remain in `01_LOGO_VECTOR/` and `02_LOGO_PNG/`.
