# MedBoard Brand Asset Kit v1.0

**Brand:** MedBoard  
**Descriptor:** Clinical Smartboard by Sentra  
**Tagline:** See Earlier. Decide Better.

## Official identity
The official mark is the approved two-row board symbol: two rounded-square data nodes, each paired with two rounded data bars. The master geometry is reconstructed directly from the approved attached icon.

## Primary usage
- Use **black on white** or **white on black** as the default identity.
- Use the optional blue-cyan accent only in digital contexts where color adds hierarchy.
- Keep a clear space of at least **1x**, where x equals the thickness of one horizontal bar in the mark.
- Do not stretch, rotate, add shadows, redraw proportions, or place the logo on low-contrast backgrounds.

## Typography
The lockups are outlined vectors, so no font installation is required to use the official logo files. Editable source files reference **Inter Display Bold** and **Inter**; font files are intentionally not included.

## Folders
- `00_GUIDELINES/` - brand guideline PDF
- `01_LOGO_VECTOR/` - SVG, PDF, EPS logo masters
- `02_LOGO_PNG/` - transparent raster exports
- `03_APP_ICONS/` - favicon and app icon assets
- `04_SOCIAL/` - Open Graph/social cards
- `05_BRAND_TOKENS/` - JSON/CSS tokens and web manifest
- `06_NEXTJS_READY/` - ready-to-drop Next.js metadata assets
- `07_SOURCE_MASTER/` - editable SVG source layouts (no font files)
- `08_PREVIEWS/` - visual brand sheet preview

## Brand principle
**Technology enables, but humans decide.**
