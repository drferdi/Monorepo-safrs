# Code of conduct

MedBoard adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

In short: be respectful, give and accept constructive feedback, and put patient safety and
privacy first. Harassment, discrimination and the sharing of anyone's private or clinical
information are not acceptable.

## Scope

This code applies in every project space (repository, issues, pull requests, reviews and the
MedBoard application's own collaboration features such as Sentrapedia contributions and team
chat) and when someone represents the project elsewhere.

## Reporting

Report unacceptable behaviour privately to the project owner through
https://ferdiiskandar.com. Reports are handled confidentially, and the owner decides on the
response, following the enforcement guidelines of the Contributor Covenant.
