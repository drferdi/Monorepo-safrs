The LFS quota is per account, not per repository, so the sibling private data repository that `scripts/private-data.mjs` already points `theoracle/index/` at would move the growth into the same 10 GiB and fix nothing. Bandwidth was uncounted before: both CI jobs pull LFS, and `setup-server.sh` installs `git-lfs` with `git lfs install --system`, so the server's routine `git pull` also downloads the 53 MB object even though the container takes its index from the image.
