Cloudflare flattens the apex CNAME, so it coexists with the Hostinger `MX` at the same name.
- **Changing a record's type in Cloudflare deletes and recreates it**, which the dialog warns about. Record count is unchanged at **17 of 17** before and after.

- Failure never disturbs the workspace: an unavailable or failed call produces a message only, and the route's 503 reads as the ordinary state of an instance without a database rather than an error.
