# TheOracle provenance (archive)

Source records for TheOracle's knowledge, kept as an archive (Gaffer, 2026-10-18). No runtime, build or test code reads
this folder; the live index is `theoracle/index/`, verified by its `manifest.json`.

- `oracle-ii/`: the former Oracle II sources, evidence, QA reports, checksums and tools (about 300 files). Its own
  `README.md` and `QA_REPORT.md` describe the contents.

Do not edit these files to change runtime behaviour; change `theoracle/sources/` and rebuild the index instead.
