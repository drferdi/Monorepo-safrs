# Sentrapedia website documentation

Start with [SPDS Read First](spds/read_first.md) and the machine-readable
[`SITE_GENOME.yaml`](../SITE_GENOME.yaml).

`docs/spds/` is the authoritative project record for purpose, scope,
requirements, architecture, risk, verification, operations, privacy, and the
healthcare non-device boundary. The remaining documents in this folder are
supporting implementation and migration evidence. When legacy wording conflicts
with current implementation or evidence, SPDS and the current evidence take
precedence.
