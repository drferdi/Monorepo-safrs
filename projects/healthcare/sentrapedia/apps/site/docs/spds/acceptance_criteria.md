# Acceptance Criteria

## Function
Define release acceptance conditions.

A candidate is acceptable only when lifecycle commands exit 0, manifest hashes match, browser review finds no overflow at 320/390/desktop widths, reduced motion exposes content, contact failures do not claim success, healthcare claims preserve physician authority, and all release-blocking UNKNOWN items are either resolved or explicitly accepted by Gaffer.
