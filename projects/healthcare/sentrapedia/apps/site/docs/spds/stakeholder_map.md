# Stakeholder Map

## Function
Stakeholder Map preserves shared project language and responsibility.

Gaffer owns purpose, claims, risk acceptance, pricing, release, and production decisions. Engineering maintains implementation and evidence within delegated scope. Visitors include physicians and institutions. Resend is an optional external processor. “Draft” means content requiring physician review; “synthetic” means no real patient identity or record; “accepted” means provider acknowledgement, not confirmed delivery.
