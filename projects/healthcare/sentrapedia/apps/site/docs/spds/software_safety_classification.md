# Software Safety Classification

## Function
Decide applicability of medical software lifecycle classification.

**DECISION:** IEC 62304 software safety classification is not applicable because this website is not medical device software and has no medical purpose. No Class A, B, or C is assigned. A future patient-specific or clinical-decision capability would invalidate this decision and require new human approval and regulatory analysis.
