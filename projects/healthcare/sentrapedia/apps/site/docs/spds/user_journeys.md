# User Journeys

## Function
User Journeys defines user interaction with the public website.

Primary journeys are: understand the Sentrapedia identity; inspect physician-centered workflows; review FAQ and pricing placeholders; and send a general inquiry without patient information. All journeys preserve keyboard access, reduced motion, responsive layout, explicit failure states, and physician authority.
