# Clinical Requirements

## Function
Define healthcare communication constraints.

The website must preserve physician decision authority, label outputs as drafts/examples, use no real patient data, avoid claims of validated clinical benefit, avoid automated-diagnosis implications, and route general inquiries away from patient information. Any change to these boundaries requires Gaffer's explicit clinical review.
