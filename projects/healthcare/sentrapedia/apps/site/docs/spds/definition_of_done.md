# Definition Of Done

## Function
Define completion for a scoped change.

A change is done when authored and generated files agree, focused and full capsule gates pass, browser evidence covers relevant viewports/interactions, docs and handoff reflect current state, risk is stated, scope-owned files alone are staged, and Gaffer has approved any release, clinical, credential, or irreversible action.
