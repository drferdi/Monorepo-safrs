# Adr-0001

## Function
Decide the website's standalone runtime and contact boundary.

## Status

Accepted by Gaffer's approved migration direction on 2026-10-14.

## Decision

Keep the public site as a self-contained static subsystem inside the Sentrapedia product capsule, with a small Node.js preview/server layer. Build output and third-party browser assets remain local to `apps/site`. The optional contact relay validates input, rejects patient-like content, restricts origin and rate, and returns success only after Resend acceptance.

## Consequences

The site subsystem can be tested independently, while ownership, release, and standalone proof remain part of the parent Sentrapedia capsule. Production delivery, infrastructure, telemetry, and retention remain separate approvals.
