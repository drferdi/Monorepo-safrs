# Intended Medical Use

## Function
Define whether the website has an intended medical purpose.

**DECISION:** Intended medical use is none. This site subsystem is marketing and demonstration software. It does not diagnose, monitor, predict, recommend treatment, calculate clinical risk, control a device, or provide patient-specific output. Healthcare examples are synthetic and describe a separate product concept.
