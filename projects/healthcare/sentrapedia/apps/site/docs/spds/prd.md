# Product Requirements Document

## Function
Define product requirements for the public website.

## Required capabilities

1. Present Sentrapedia identity and value without unsupported efficacy claims.
2. Explain physician-centered workflows with synthetic examples.
3. Provide keyboard-usable navigation, disclosure controls, and visible focus.
4. Respect reduced motion and responsive layouts from 320 px upward.
5. Serve all runtime assets locally.
6. Reject patient-like contact content and fail closed when delivery is unavailable.
7. Build and verify independently of the monorepo root.
