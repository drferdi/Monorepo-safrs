# Brainstorm Protocol

## Input

- Client / organization
- Problem or opportunity
- Known facts
- Unknowns
- Requested outcome
- Time constraint

## Session output

1. Problem framing
2. 2–4 plausible solution directions
3. Feasibility notes
4. Key risks / dependencies
5. Questions requiring research or client clarification
6. Candidate next step
7. Any decision requiring Founder/domain-owner approval

## Anti-patterns

- solution before problem;
- inviting everyone;
- quoting an unapproved price;
- promising delivery dates during ideation;
- treating a technically possible idea as commercially or legally approved.
