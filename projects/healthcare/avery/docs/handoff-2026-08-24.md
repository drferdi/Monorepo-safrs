# Avery — Handoff sesi pengerjaan tech-debt & hardening (2026-08-24)

Sesi ini mengeksekusi daftar perbaikan hasil audit kapsul Avery. Otorisasi grup WhatsApp
**sengaja tidak diubah**: Avery hanya melayani 5 founding member di grup Sentra community
(keputusan Chief; butir 8 tech-debt `group_policy: open` TIDAK dijalankan).

## Yang sudah dikerjakan

### 1. Hardening control center web (`scripts/control_center.py`)
- Semua header `Access-Control-Allow-Origin: *` dihapus dari seluruh endpoint.
- Guard anti-CSRF dua lapis:
  - request dengan header `Origin` yang bukan `http://127.0.0.1:8989` → 403;
  - POST `/api/action` wajib header `X-Avery-Control: 1` (tidak bisa dikirim form
    lintas-origin tanpa preflight yang disetujui server).
- Token auth opsional: set env `AVERY_CONTROL_TOKEN` → semua `/api/*` menuntut
  header `X-Avery-Token` yang cocok.
- Aksi `run_script`: allowlist ketat (`KNOWN_SCRIPT_NAMES`) + penolakan path traversal
  (`Path(script_name).name != script_name` ditolak). Sebelumnya `..\..\evil.bat` lolos.
- Aksi `stop`: kill by PID (gateway dari `gateway.pid` + bridge via query CIM
  `whatsapp-bridge`) — bukan lagi `Stop-Process -Name node,python` kill-all.
- Path hardcoded user-specific diganti env var: `AVERY_AVATAR_PATH`, `AVERY_SCRIPTS_DIR`
  (default `~/Documents/scripts`). Avatar default kosong → endpoint `/avatar.jpg` 404 aman.

### 2. Hardening konsol Electron (`console/main.js`, `console/renderer/renderer.js`)
- IPC `system:runScript`: allowlist sama dengan control center + tolak path traversal.
- Aksi `stop`: taskkill per-PID via helper `getBridgePids()` + pid gateway.
- Path hardcoded `C:\Users\drfer\...` → env var yang sama dengan di atas.
- Metrik palsu `active_sessions: gwRunning ? 6 : 0` diganti `null` (jujur); renderer
  menampilkan "SESI: N/A" / "—".

### 3. Penyelesaian rename nama lama → Avery
- Diganti di 11 berkas: `docs/architecture.md`, `docs/README.md`, `docs/1-human/*`,
  `docs/2-agent/*`, `docs/3-governance/*`, `deploy/.env.example`.
- Sengaja DIBIARKAN (historis): `CHANGELOG.md`, `docs/superpowers/plans/*`,
  `scripts/rename-capsule.ps1/.bat`, riwayat git.
- `docs/tech-debt-2026-08-24.md` butir #6 diperbarui dengan catatan pelengkap.

### 4. Sinkronisasi `capabilities.json`
- Naik ke `0.2.0`; `action-approval-gate` dipindah dari `not_yet` ke `capabilities`
  (broker outbound approval sudah nyata); jumlah skill (18) tercatat di description.

### 5. CI lokal baru: `scripts/ci-checks.ps1`
Tiga gerbang: (1) unit test Python (`PYTHONPATH=src`), (2) scan data sensitif pada
folder sumber saja (pola identik `sync-profile-to-repo.ps1`: nomor Indonesia, JID LID,
JID grup, kunci OpenRouter/OpenAI), (3) grep anti-nama-lama dengan daftar pengecualian
historis. Catatan implementasi: enumerasi dibatasi folder sumber agar tidak menyentuh
`runtime/` (3+ GB, junction rusak); PowerShell 5.1 kompatibel (tanpa
`[IO.Path]::GetRelativePath`).

### 6. Ketahanan store korupsi JSON (`src/avery_outbound/store.py`)
- `_load()` melempar `StoreError` yang jelas untuk berkas korup/tidak terbaca.
- `list()` dan `expire_stale()` melewati berkas korup dan mencatat event
  `corrupt_file` ke ledger (metadata saja).
- Test baru `tests/test_store.py::CorruptFileTests` (3 uji).

## Yang BELUM dikerjakan (butuh keputusan/sesi lanjutan)
1. **Lint/type-check**: ruff/mypy belum terpasang — butuh persetujuan dependency baru
   (aturan repo: no new deps tanpa approval). Saat ini hanya `py_compile`.
2. **Konsolidasi dua konsol** (web `control_center.py` ≈1.2k baris dengan HTML ter-embed
   vs Electron `console/`): logika health-check/log-parsing masih duplikat. Usulan:
   ekstrak HTML/CSS/JS ke file statis terpisah atau satukan jadi satu aplikasi.
3. **Respawn bridge otomatis oleh gateway**: butuh patch runtime Hermes upstream
   (`patches/hermes-0.20.5/`) — belum disentuh.
4. **Uji `restart-gateway.sh` di Linux**: tidak bisa diverifikasi dari Windows; wajib
   diuji sebelum migrasi VPS (runbook `docs/deploy-hostinger.md`).
5. **Hermes runtime tertinggal ~115 commit upstream** (tech-debt #10): patch ingress
   bisa hilang saat update; jalankan `apply-hermes-patches.ps1` setelah update.
6. Env var baru untuk deployment: pertimbangkan menambahkan `AVERY_SCRIPTS_DIR`,
   `AVERY_AVATAR_PATH`, `AVERY_CONTROL_TOKEN` ke `deploy/.env.example`.
