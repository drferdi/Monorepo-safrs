# Release Checklist

- [ ] `npm run check:json`
- [ ] `npm run build`
- [ ] `npm test`
- [ ] `npm run validate:templates`
- [ ] Registry count equals actual role-package count.
- [ ] All role IDs are unique.
- [ ] No secret patterns or `.env` files included.
- [ ] Source provenance date reviewed.
- [ ] Regulatory-status manifest reviewed.
- [ ] CHANGELOG and VERSION updated.
- [ ] Archive opens successfully.
- [ ] SHA-256 checksum generated.
