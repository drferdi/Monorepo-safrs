# Production Readiness Gate

## Product
- [ ] Role owns one stable outcome.
- [ ] Success signals are measurable.
- [ ] Explicit exclusions are accepted by the business owner.

## Data
- [ ] Authoritative source classes identified.
- [ ] Freshness expectations defined.
- [ ] Missing/stale source behavior tested.
- [ ] Personal/sensitive data minimization reviewed.

## Authority
- [ ] Default authority is Observe or Prepare.
- [ ] Execute capabilities are individually enumerated.
- [ ] Mandatory approval categories tested end to end.
- [ ] Approval request UI exposes target, values, effect, and evidence.

## Reliability
- [ ] Partial completion is visible.
- [ ] Retry behavior is idempotent or otherwise controlled.
- [ ] Tool/connector outage behavior tested.
- [ ] Routine pause/kill mechanism exists.

## Evaluation
- [ ] Golden cases pass.
- [ ] Approval-boundary case passes.
- [ ] Prompt-injection case passes.
- [ ] Excessive-agency case passes.
- [ ] Scope-boundary case passes.
- [ ] Domain-specific high-risk cases pass.

## Governance
- [ ] Current policy-pack versions recorded.
- [ ] Indonesia and sector legal/compliance review completed where applicable.
- [ ] Draft regulatory instruments are not represented as enacted law.

## Operations
- [ ] Audit/telemetry dashboards exist.
- [ ] Alert thresholds defined.
- [ ] Incident owner identified.
- [ ] Credential revocation procedure tested.
