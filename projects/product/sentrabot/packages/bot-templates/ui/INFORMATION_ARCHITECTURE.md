# Information Architecture

## Level 1 — Template discovery
- Search roles
- Featured roles (maximum 8)
- Domain filters: Leadership, Corporate, Commercial, Operations, Technology, Healthcare, Research & Education, Indonesia & Public Sector
- Authority filter: Observe / Prepare / Can act with approval
- `Build custom role` is a separate creation pathway, not a role card.

## Level 2 — Role inspection
A selected role panel displays:
- primary outcome
- ownership
- explicit exclusions
- default authority
- regulated / sensitive-data indicators
- required approval categories
- recommended outputs

## Level 3 — Configure bot
Sections:
1. Identity
2. Mission & scope
3. Sources of truth
4. Authority & approvals
5. Output contract
6. Skills & routines
7. Evaluation / test run

## Level 4 — Operational view
Persistent header:
- role + version
- authority level
- data freshness state
- active policy packs
- routine state
- last successful evaluation

Operational content prioritizes **exceptions and decisions**, not chat chronology.
