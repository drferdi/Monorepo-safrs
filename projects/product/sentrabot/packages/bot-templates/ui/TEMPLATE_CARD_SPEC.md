# Template Card Specification

## Anatomy
- 20×20 domain icon
- title, max 2 lines
- outcome sentence, 2–3 lines
- domain chip
- authority chip (`Prepare-first` by default)
- optional `High oversight` risk chip
- chevron / selection affordance

## Selected state
Use all of:
- accent border
- subtle accent surface
- check indicator + text `Selected`

Do not rely on color alone.

## Card copy formula
**[Outcome verb] + [operational object] + [decision/risk benefit].**

Avoid persona copy such as “Your genius legal friend.” Prefer “Keeps legal obligations, deadlines, and counsel decisions visible.”

## Responsive grid
- ≥ 1440px: 3 columns
- 900–1439px: 2 columns
- < 900px: 1 column
