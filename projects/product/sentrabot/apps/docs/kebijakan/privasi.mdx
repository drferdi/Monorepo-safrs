---
title: "Kebijakan Privasi"
description: "Bagaimana SentraBot memperlakukan data Anda."
---

Berkas, riwayat percakapan, memori agen, dan kredensial tersimpan di mesin yang Anda kendalikan, terenkripsi dengan kunci milik instalasi Anda.

Dua jalur panggilan model:

| Mode | Jalur | Peran Sentra |
|---|---|---|
| **Sentra Managed AI** | Potongan konteks → Sentra AI Gateway → penyedia model | Pemroses data |
| **BYOK** | Runtime Anda → penyedia model, langsung | Tidak ada |

Analitik produk **mati secara bawaan** dan hanya mengirim metadata bila Anda menyalakannya. Isi percakapan, berkas, memori, dan kredensial tidak pernah dikumpulkan.
