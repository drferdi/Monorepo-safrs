# Data — Kediri History

## Classes

| Class | Location / notes | Sensitivity |
| --- | --- | --- |
| Public narrative & visuals | App content, `project-images/`, `project-video/` | Public / licensed assets only |
| Research notes | `research/` | Review before publish; no secrets |
| Environment | `.env.example` (template only) | No production credentials in git |
| Runtime env | `.env.local` (local, gitignored) | Never commit |

## Rules

- No production credentials, private keys, or real personal data in the repository.
- Historical claims must remain traceable; uncertainty stays explicit in product copy.
- R3 surfaces (production publish, live credentials) require Chief authorization.
