# Architecture Lock

This file defines the implementation authority boundary for Kediri — A Living Civilization v0.1.

1. The Bibles define product, historical, visual, UX and technical intent.
2. `MASTER_IMPLEMENTATION_PLAN.md` defines execution order and Definition of Done.
3. The original research corpus is preserved unchanged but is not automatically published truth.
4. Sentra-GSAP v1.0.0 is binding for GSAP structure, ownership, responsive choreography, performance and QA.
5. Agents may not replace the approved stack, move historical claims into React/GSAP, auto-publish imported research, or silently reinterpret a Bible.
6. If implementation conflicts with the canon, stop the conflicting implementation and surface the conflict for explicit human decision.

**Human authority remains final.**
