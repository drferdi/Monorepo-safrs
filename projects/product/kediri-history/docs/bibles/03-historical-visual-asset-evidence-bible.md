# KEDIRI — A Living Civilization
## Historical Visual Asset & Evidence Bible

**Version:** 0.1  
**Purpose:** Define what the audience may see, what each visual actually proves, who owns it, how it may be transformed, and what must never be presented as historical evidence.

# CORE RULE

# IF WE CANNOT PROVE WHAT AN IMAGE IS, WE DO NOT PRESENT IT AS HISTORY.

---

# 1. Why This Bible Exists

Cinematic historical design creates a special danger: the more convincing a visual becomes, the easier it is for audiences to mistake interpretation for evidence.

A photorealistic Jayabhaya can imply an authenticated likeness. A spectacular Daha reconstruction can imply archaeological certainty. An AI-generated inscription can quietly replace the real object. A colonial image can be detached from the power structure that produced its caption.

Every production asset must therefore follow this chain:

`Historical Claim → Evidence → Source/Object → Visual Asset → Rights → Treatment → Motion → Public Presentation`

No asset skips the chain.

---

# 2. Visual Evidence Classes

## V0 — PRIMARY OBJECT
The actual historical object or faithful reproduction.

Examples: inscription, manuscript, law, archival document, historical engineering drawing.

Permitted: crop, magnify, responsive resize, controlled relighting, camera motion.  
Forbidden: alter characters, create missing historical information, misrepresent discovery location.

## V1 — DOCUMENTARY HISTORICAL IMAGE
Photograph, film frame, map, drawing, or documentary image made during or reasonably near the period depicted.

It proves what was captured by that source—not every later interpretation attached to it.

## V2 — VERIFIED CONTEMPORARY DOCUMENTATION
Current photography/video of surviving sites or modern institutions.

Examples: Brantas, Jembatan Lama, Gereja Merah, Dhoho.

## V3 — EVIDENCE-CONSTRAINED RECONSTRUCTION
A reconstruction built from real evidence but containing inference.

Examples: political influence zones, historical transport network, approximate royal landscape.

Must be labelled when uncertainty matters.

## V4 — ARTISTIC INTERPRETATION
Obviously interpretive visual material used for atmosphere or conceptual storytelling.

Examples: symbolic throne, letters becoming armies, fractured geometry for Ganter.

## V5 — FOLKLORE VISUALIZATION
Non-documentary representation of tradition or legend.

Examples: Calon Arang, Mpu Bharada sacred-water tradition, Lembu Suro, Kediri Curse.

Must show **TRADITION / FOLKLORE** classification.

---

# 3. Rights Classes

## R0 — Public Domain / CC0
Preferred.

## R1 — Open License
Examples CC BY / CC BY-SA; attribution and license compliance required.

## R2 — Government / Institutional Use
Institutional publication does not automatically equal unrestricted reuse. Confirm terms.

## R3 — Permission Required
Museum photography, corporate archive, private collection, prominent contemporary photography.

## R4 — Editorial / Commercial License
News agencies / commercial archives.

## R5 — Reference Only
May inform research or design, never ship publicly.

Evidence authenticity and copyright permission are separate questions.

# 4. Mandatory Provenance Metadata

Every asset requires:

- Asset ID
- canonical title
- depicted subject
- historical date depicted
- asset creation date
- creator / photographer
- holding institution
- inventory / shelfmark
- canonical source URL or catalogue reference
- visual evidence class
- rights class
- license / permission status
- permitted transformations
- credit line
- context note
- uncertainty note
- scene assignments
- publication status

Never keep production evidence as `bridge-old.jpg` with no provenance.

Suggested ID style:

`KD-V1-BRIDGE-1920-KITLV-10007564-master.tif`

# 5. Priority Institutions / Repositories

## Museum Nasional Indonesia — CRITICAL

Primary targets:

- Prasasti Kwak I — catalogue/inventory reference already identified during research as E.6.
- Prasasti Harinjing — D.173.
- Prasasti Hantang / Ngantang — D.9.

Acquisition request should include high-resolution front/reverse images, raking light, scale image, catalogue metadata, web reuse rights and derivative-motion rights.

### Kwak caution
The object should never be visually staged as if excavated in Kediri if its documented findspot is elsewhere. Its role in the Kediri project is civic-historical and epigraphic.

Ceremonial Manusuk Sima replicas must always be labelled **replica**.

## Indonesian cultural heritage institutions / BPKW XI
Targets: heritage documentation, archaeological imagery, Gereja Immanuel, Selomangleng, inscription/site reports.

## Perpustakaan Nasional / Khastara
Priority for Panji manuscript traditions. High-resolution selected folios should be requested with explicit reproduction permission.

Surviving later manuscripts are evidence of the tradition's afterlife—not direct images of the twelfth-century Panjalu court.

## UNESCO Memory of the World
Use as evidence of global documentary significance. UNESCO recognition does not grant image rights to every holding.

## Leiden University Libraries / KITLV
High-priority colonial and archaeological photography: Brantas, streets, Kelud, colonial landscape, infrastructure, archaeological material.

## Rijksmuseum
A major asset source. Planning research identified a c.1925–1930 public-domain photographic album covering Java sugar factories including **actual PG Meritjan**, with workers, machinery, rail, settlements and aerial material.

This is crucial: do not use generic sugar-factory imagery where actual Meritjan material survives.

## Wereldmuseum / Tropenmuseum collections
Priority for Jembatan Lama / Brantas historical photography, including imagery catalogued as the **raised Brantas bridge at Kediri**.

## Nationaal Archief Netherlands
Critical for 1948 military photography around Kediri and the Brantas. Original military captions must be treated critically; archive terminology is evidence of the archive, not neutral narration.

## Colonial map collections
Use real maps where possible: Residentie Kediri, city plans, transport survey maps. Never fake an “ancient” or “colonial” map by putting parchment texture over modern GIS.

## Kementerian Perhubungan / airport operator
Primary source for Dhoho modern documentation and legal naming.

## Gudang Garam / Surya Dhoho Investama
Formal archive collaboration should be pursued for founder-era history, industrial expansion, workforce, corporate transition and Dhoho infrastructure.

# 6. Scene-by-Scene Asset Rules

## Scene 00 — Present Day
**Class:** V2  
Commission original Kediri photography: Brantas, twin bridges, streets, station, markets, human activity, skyline. Opening and finale should share a matching camera position.

## Scene 01 — 879 Kwak
**Class:** V0  
P0 acquisition. Museum-grade macro photography. No fake discovery site, no altered characters, no ceremonial replica presented as original.

## Scene 02 — 921 Kadhiri / Harinjing
**Class:** V0  
P0 acquisition. Epigrapher must identify the actual relevant text area before any highlighted animation.

## Scene 03 — Carama
**Status:** RESEARCH HOLD  
No hero artefact until holding institution, accession, image, transcription and rights are independently established.

## Scene 04 — Airlangga / Division
**Class:** V3 + V5  
Use evidence-constrained geography and symbolic tradition. Do not draw false precise borders if scholarship supports only broad zones.

## Scene 05 — Daha
**Class:** V3  
No photoreal “Daha, 1100 AD” presented as certain. Use incomplete, restrained, labelled reconstruction.

## Scene 06 — Panjalu Jayati
**Class:** V0  
P0 Hantang acquisition. Hero is the actual inscription and phrase—not an imaginary royal face.

## Scene 07 — Bharatayuddha
Use sourced manuscript tradition + V4 literary interpretation. Never call a later copy “the original manuscript of 1157” without provenance.

## Scene 08 — Panji
Use Perpusnas and other later manuscript collections to show cultural transmission. Do not imply later manuscript illustrations are authenticated portraits of historical characters.

## Scene 09 — Ganter
**Class:** V3 + V4  
Maps, political movement, fractured geometry. No fake cinematic battlefield presented as documentary.

## Scene 10 — Jayakatwang
**Class:** V3  
Strategic and textual treatment rather than invented attack scene.

## Scene 11 — Yuan / Raden Wijaya / Daha
Historical map/symbolic vector treatment. No generic “Mongol warrior” stock used as evidence of the Java expedition.

## Scene 12 — Jayabaya After Jayabaya
Historical layer uses Jayabhaya evidence. Prophetic layer uses visibly later textual tradition. Always show chronological distance.

## Scene 13 — Shadow Archive
Calon Arang / Lembu Suro / Curse are V5. Kelud itself can use real historical and contemporary documentary imagery, with folklore layered over it.

## Scene 14 — 1678
Use strategic reconstruction and clearly dated later depictions when available. A nineteenth-century illustration of 1678 is still a later illustration.

## Scene 15 — Sugar Changes the Land
Rijksmuseum Meritjan material should show the full industrial ecosystem: machinery + workers + rail + nearby settlement + landscape.

## Scene 16 — 1869 Bridge
Historical photos + real engineering geometry + modern commissioned photography. Reconstruct from the actual bridge, not generic truss geometry.

## Scene 17 — Colonial City
Real maps, station archive, streets, Gereja Merah. Never use sepia nostalgia as the sole interpretive frame.

## Scene 18 — 1912 Bridge Rise
Historical post-raising imagery exists. Exact 1.5m motion remains gated on archival verification of mechanism/date/measurement.

## Scene 19 — People Between Monuments
Prioritize family, community, labour, market, education and religious-life archives. This is where the public-memory program becomes essential.

## Scene 20 — 1942 Occupation
Current visual evidence gap. Research ANRI, Perpusnas newspapers, Japanese archives, railway/factory/local family archives. Generic Japanese-war image must be labelled contextual if ever used.

## Scene 21 — 1947–48 Revolution
Use real Meritjan industrial imagery and real 1948 Kediri military archive where appropriate. Exact mortar-production visualization remains blocked until claim is verified.

## Scene 22 — 1950 Republic
Acquire official legal scan / publication metadata for the republican local-government framework.

## Scene 23 — 1958 Gudang Garam
Formal company archive request. Show people, workplace, urban relationship and scale; never reduce to logo/factory advertisement.

## Scene 24 — Modern Industrial Economy
Data visualization is itself evidence. Every chart requires source, year, unit and definition.

## Scene 25 — Twin Bridges
Commission a precision photo pair and, where possible, camera-match historical bridge photography.

## Scene 26 — Dhoho
Use Kemenhub/operator/company official material + original contemporary production. Airport drone work only with proper permission and aviation safety procedures.

## Finale — 2026
Use real Kediri. The final proof of continuity is contemporary civic life, not generated imagery.

# 8. Reconstruction Policy

## Level 0 — Document Only
No speculative reconstruction: inscriptions, laws, real archive.

## Level 1 — Structural Reconstruction
Known geometry may be derived: bridge, map, documented machinery.

## Level 2 — Evidence-Constrained Environment
Some facts known, environment inferred: Daha landscape, broad political geography.

## Level 3 — Symbolic / Legendary
No claim of visual authenticity: Mpu Bharada, Calon Arang, prophetic Jayabaya.

---

# 9. AI-Generated Image Policy

AI may generate atmosphere: fog, clouds, dust, abstract transitions, non-documentary environmental extensions.

AI may assist restoration only after unaltered masters are preserved and without changing historical semantics.

AI must never be presented as factual evidence for:

- real Jayabhaya likeness;
- Airlangga portrait;
- authentic ancient Daha photograph;
- inscription/manuscript;
- colonial/1948 documentary photograph;
- archaeological ruin;
- historical map.

# AI IS A PRODUCTION TOOL, NOT AN ARCHIVE.

---

# 10. Restoration Rules

Every restored asset has:

1. immutable master;
2. production derivative.

Permitted: dust/scanner artefact cleanup, tonal correction, minor non-semantic restoration.

Not silent: adding/removing people, buildings, signs, uniforms, inscription characters, semantic architecture.

If meaningful content is reconstructed, classification becomes V3.

---

# 11. Colonial Archive Ethics

Every colonial asset stores photographer, institution, original title, date, terminology and context. Politically loaded archival captions never become invisible project narration.

If outdated terminology must be quoted academically, identify it as original archival language.

---

# 12. Human Dignity Rule

War imagery is not decoration. Prisoners, injured people, bodies, humiliation or visible distress require heightened editorial review.

# DIGNITY OVERRIDES SPECTACLE.

---

# 13. Technical Asset Standard

Historical hero masters: TIFF where available; high bit depth / embedded profile preferred.  
Contemporary stills: RAW, high-resolution.  
Video: 4K minimum, 10-bit preferred for major production.  
Web: responsive AVIF/WebP/JPEG/MP4 derivatives as appropriate.

Masters are never discarded.

---

# 14. Image Treatment Rules

- no default sepia;
- original material color preserved;
- default no colorization of monochrome archives;
- heavy 2.5D parallax avoided on documentary photographs;
- archival image is shown as a whole before aggressive crop/zoom where practical;
- crop may not erase important human/historical context;
- real maps, reconstruction maps and modern GIS use distinct visual language;
- modern responsive crops require documented safe zones.

---

# 15. Evidence UI Requirement

For an important object, visitors should be able to see:

**OBJECT**  
**DATE**  
**INSTITUTION**  
**INVENTORY**  
**EVIDENCE TYPE**  
**WHAT IT SUPPORTS**  
**WHAT IT DOES NOT PROVE**

Teaching the limit of a source is part of teaching history.

---

# 16. Asset Status System

- **GREEN — Production Ready:** evidence verified, rights cleared, master acquired, metadata complete.
- **BLUE — Verified / Waiting Rights:** source solid, permission incomplete.
- **AMBER — Visual Found / Evidence Incomplete:** do not publish yet.
- **RED — Claim Without Adequate Visual Proof:** research required.
- **BLACK — Prohibited Representation:** misleading regardless of visual quality.

# 21. Final Acceptance Test

Before any visual ships, answer:

- Do we know what this depicts?
- Do we know when it was created / what date it depicts?
- Is it actually Kediri?
- Is provenance traceable?
- Can it legally be used and transformed?
- What claim does it support?
- What does it not support?
- Has alteration changed historical meaning?
- Does the audience know whether it is evidence, reconstruction or folklore?
- Are people represented with dignity?
- Does motion preserve the evidence?

If one critical answer fails, the asset does not ship.
