# Glossary

## Purpose

This document defines the common terminology used throughout the project to ensure consistent communication between humans and AI agents.

## Core Principles

* Use consistent terminology.
* Avoid duplicate definitions.
* Prefer established terms.
* Update definitions when concepts evolve.

## Guidelines

**Architecture** — The high-level organization of the system.

**Context** — Information required to understand and complete a task correctly.

**Knowledge** — Stable project information that should be documented.

**Memory** — Long-term user preferences that apply across conversations. It is not a replacement for project documentation.

**Project Instructions** — Persistent rules that define how AI should behave within this project.

**Verification** — Objective confirmation that work satisfies its intended requirements.

## Expected Behavior

Use these definitions consistently across conversations, documentation, and implementation. When introducing new terminology, recommend adding it to this glossary.
