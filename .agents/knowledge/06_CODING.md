# Coding

## Purpose

This document defines the coding standards expected throughout the project. Code should prioritize clarity, maintainability, and consistency over cleverness or unnecessary optimization.

## Core Principles

* Write readable code.
* Keep functions and components focused.
* Follow existing project conventions.
* Minimize complexity.
* Optimize only when justified.

## Guidelines

Write code that is:

* Simple and self-explanatory.
* Modular and reusable.
* Consistent with the existing architecture.
* Easy to test and maintain.

Avoid:

* Dead code.
* Magic values.
* Unnecessary abstractions.
* Premature optimization.
* Large unrelated refactors.

When modifying existing code, preserve style and behavior unless improvement is explicitly required.

## Expected Behavior

Produce code that is easy for other developers and AI agents to understand, maintain, and extend.
