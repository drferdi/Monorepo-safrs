# Objectives

## Purpose

This document defines the long-term objectives of the project. Every recommendation, design decision, and implementation should support these objectives.

## Core Principles

* Solve real problems.
* Deliver measurable value.
* Improve human capability.
* Preserve long-term maintainability.
* Build for continuous evolution.

## Guidelines

When making decisions, prioritize:

* Long-term value over short-term convenience.
* Simplicity over unnecessary complexity.
* Reliability over feature quantity.
* Consistency over novelty.
* Reusable solutions over isolated implementations.

When multiple solutions are possible, recommend the one that best supports these objectives.

## Expected Behavior

Every task should contribute to a system that becomes easier to understand, maintain, extend, and improve over time.
